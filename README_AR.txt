حزمة رفع الملف التعليمي إلى موقع حسين بدر
========================================

اسم القسم: الملفات التعليمية
العنوان: تعلم اللغة الإنجليزية من الصفر إلى الاحتراف والإتقان
الاسم الإنجليزي: English From Zero
إعداد وتأليف: حسين بدر
عدد صفحات ملف PDF: 1392 صفحة

محتويات المجلد:
- index.html : صفحة عرض احترافية جاهزة للويب باللغة العربية.
- files/English_From_Zero_Hussein_Badr.pdf : ملف PDF الأصلي كما تم استلامه، دون تعديل المحتوى.
- assets/cover.jpg : صورة معاينة مستخرجة من الصفحة الأولى للملف.
- metadata.json : بيانات العنوان والتصنيف والمؤلف والملف والصورة.

طريقة الرفع:
1. فك ضغط الحزمة.
2. ارفع مجلد english-from-zero كاملًا إلى مجلد ملفات موقعك أو مستودع GitHub Pages.
3. حافظ على بنية المجلدات والملفات كما هي؛ لا تفصل index.html عن مجلدي files و assets.
4. بعد النشر، افتح المسار english-from-zero/ لعرض صفحة الملف.
5. اربط قسم "الملفات التعليمية" في موقعك بهذا المسار.

ملاحظة:
- لم يتم تعديل أو إعادة ضغط أو إعادة تصدير ملف PDF الأصلي؛ أُدرج كما استُلم.
- معاينة PDF المضمنة تعتمد على دعم المتصفح لعرض ملفات PDF. زر التنزيل يبقى متاحًا عند عدم ظهور المعاينة.
- إذا كان موقعك يستخدم مسار نشر مختلفًا، ارفع المجلد داخل المسار المناسب مع الإبقاء على الروابط النسبية كما هي.
