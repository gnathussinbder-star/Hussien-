- بطاقات مفردات تفاعلية، لوحة تقدم وتصدير/استيراد JSON.
- خطة دراسة أسبوعية، تمرين استماع/تحدث يستخدم ميزات المتصفح المتاحة، وتمرين كتابة.

الرفع إلى GitHub Pages من الهاتف/التابلت:
1. احتفظ بنسخة احتياطية من الموقع القديم أولًا.
2. فك ضغط الملف ZIP على الجهاز.
3. ارفع الملفات العشرين نفسها إلى جذر المستودع بجانب بعضها، بحيث يكون index.html في الجذر. لا ترفع ملف ZIP وحده ولا تضع الملفات داخل مجلد جديد.
4. لا تنشئ مجلد assets لهذه النسخة. يجب أن يوجد style.css وapp.js بجانب index.html. صفحات HTML تستخدم مسارات نسبية إلى هذين الملفين.
5. بعد اكتمال النشر، افتح الموقع واضغط تحديثًا كاملًا في المتصفح. إذا بقيت نسخة قديمة، افتح نافذة خاصة أو امسح ذاكرة التخزين المؤقت.
