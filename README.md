# Hussein Badr English

منصة تعليمية مجانية لتعلّم الإنجليزية خطوة بخطوة، من A1 إلى C1: دروس قصيرة، اختبار مستوى، بطاقات مفردات، تمارين تفاعلية، ولوحة تقدم محفوظة على جهاز المستخدم.

**الموقع:** https://gnathussinbder-star.github.io/Hussien-/

## الهوية البصرية

| الاستخدام | اللون | الكود |

| الأزرار والتمييز | Yellow | `#FFD447` |

## هيكل الملفات

```
index.html            الصفحة الرئيسية
404.html              صفحة الخطأ
site.webmanifest      تثبيت الموقع على الهاتف
robots.txt            إعدادات محركات البحث
sitemap.xml           خريطة الموقع
assets/
  css/home.css        تصميم الصفحة الرئيسية
  js/home.js          الوضع الداكن وقائمة الهاتف
  files/              الملف التعليمي (PDF)
  hbe-logo-*.png      الشعار بأحجام مختلفة
  hbe-portrait.jpg    الصورة الشخصية
  og-image.jpg        صورة المشاركة (1200×630)
  favicon.svg         أيقونة الموقع
```

## إضافة الملف التعليمي

ضع ملف الـ PDF في `assets/files/` باسم `learning-guide.pdf`، أو غيّر الرابط في قسم `#guide` داخل `index.html`.

## النشر على GitHub Pages

1. ارفع محتويات المجلد إلى المستودع (فوق الملفات الموجودة، مع استبدال `index.html` ومجلد `assets`).
2. من **Settings ← Pages** اختر الفرع `main` والمجلد `/ (root)`.
3. انتظر دقيقة وافتح رابط الموقع.
