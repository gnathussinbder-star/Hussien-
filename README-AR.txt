حزمة إضافة الملف التعليمي إلى موقع حسين بدر
============================================

محتويات الحزمة:
- index.html: صفحة عرض الملف التعليمي مع قسم المعاينة.
- assets/cover.jpg: صورة الغلاف المستخرجة من الصفحة الأولى للملف الأصلي.
- files/English_From_Zero_Hussein_Badr.pdf: ملف الكورس الأصلي الكامل (1392 صفحة).

طريقة الرفع إلى GitHub Pages:
1. نزّل ملف ZIP إلى جهازك ثم فك الضغط عنه.
2. افتح مستودع موقعك: https://github.com/gnathussinbder-star/Hussien-
3. ارفع محتويات المجلد بعد فك الضغط إلى المجلد الرئيسي (Root) للمستودع.
4. حافظ على ترتيب المجلدات كما هو: assets و files.
5. عند طلب الاستبدال، استبدل index.html بالنسخة الموجودة في الحزمة.
6. لا تحذف بقية ملفات الموقع أو مجلداته. ارفع الملفات الجديدة/المعدّلة فقط.
7. انتظر اكتمال نشر GitHub Pages ثم افتح:
   https://gnathussinbder-star.github.io/Hussien-/

ما الذي سيعمل في الصفحة؟
- عرض غلاف الملف.
- زر تنزيل مباشر للـPDF.
- معاينة داخل الموقع بواسطة عارض PDF في المتصفح.
- تصميم متجاوب مع الهاتف والتابلت.

ملاحظة:
هذه الحزمة تحتوي الملف نفسه الذي رفعته، ولا تحتاج إلى رابط Google Drive خارجي.
إذا لم تظهر المعاينة داخل بعض متصفحات الهاتف، استخدم زر تنزيل PDF.
